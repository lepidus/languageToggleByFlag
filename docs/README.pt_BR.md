# Plugin Language Toggle By Flag

[English](../README.md) | [Español](README.es.md)

Este plugin adiciona uma opção de troca de idioma, com a exibição da bandeira do país correspondente

## Compatibilidade

Este ramo (`main`) é voltado ao **OJS 3.5.x**. Outras versões das aplicações são suportadas em ramos dedicados:

* OJS 3.5.x ([`main`](https://github.com/lepidus/languageToggleByFlag/tree/main))
* OJS / OPS / OMP 3.4.x ([`stable-3_4_0`](https://github.com/lepidus/languageToggleByFlag/tree/stable-3_4_0))
* OJS 3.2.x / 3.3.x ([`stable-3_3_0`](https://github.com/lepidus/languageToggleByFlag/tree/stable-3_3_0))
* OJS 3.1.x ([`stable-3_1_2`](https://github.com/lepidus/languageToggleByFlag/tree/stable-3_1_2))
* OJS 2.x ([`ojs2`](https://github.com/lepidus/languageToggleByFlag/tree/ojs2))

Pacotes prontos para instalação de cada versão estão disponíveis na [página de releases](https://github.com/lepidus/languageToggleByFlag/releases).

## Instalação

1. Acesse a área de administração do seu site através do __Painel de Controle__.
2. Navegue até `Configurações do Site` > `Plugins` > `Plugins Instalados` > `Enviar um novo plugin`.
3. Em __Enviar arquivo__, selecione o arquivo __languageToggleByFlag.tar.gz__, baixado do último release.
4. Clique em __Salvar__ e o plugin será instalado no seu site.
