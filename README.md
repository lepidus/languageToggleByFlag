# Language Toggle By Flag Plugin

[Português (Brasil)](docs/README.pt_BR.md) | [Español](docs/README.es.md)

This plugin adds a language switch option, with the display of the corresponding country's flag

## Compatibility

This branch (`main`) targets **OJS / OPS / OMP 3.5.x**. Other application versions are supported in dedicated branches:

* OJS / OPS / OMP 3.5.x ([`main`](https://github.com/lepidus/languageToggleByFlag/tree/main))
* OJS / OPS / OMP 3.4.x ([`stable-3_4_0`](https://github.com/lepidus/languageToggleByFlag/tree/stable-3_4_0))
* OJS 3.2.x / 3.3.x ([`stable-3_3_0`](https://github.com/lepidus/languageToggleByFlag/tree/stable-3_3_0))
* OJS 3.1.x ([`stable-3_1_2`](https://github.com/lepidus/languageToggleByFlag/tree/stable-3_1_2))
* OJS 2.x ([`ojs2`](https://github.com/lepidus/languageToggleByFlag/tree/ojs2))

Ready-to-install packages for each version are available on the [releases page](https://github.com/lepidus/languageToggleByFlag/releases).

## Installation

1. Enter the administration area of your website through the __Dashboard__.
2. Navigate to `Website Settings` > `Plugins` > `Installed Plugins` > `Upload a new plugin`.
3. Under __Upload file__ select the file __languageToggleByFlag.tar.gz__, downloaded from the latest release.
4. Click __Save__ and the plugin will be installed on your website.
